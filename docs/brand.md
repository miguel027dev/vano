# Brand system

The canonical VANO palette is Deep Orange-Red `#FF3D00`, Bright Orange `#FF7A00`, Soft Orange `#FFA552`, Warm Amber `#FFD280` and Ivory/Cream `#FFF7ED`.

Static assets use stable semantic filenames. Cache invalidation is handled by the application build identifier rather than version numbers embedded in filenames.

Light and Black themes share the same component hierarchy and responsive layout.
