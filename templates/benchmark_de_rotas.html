API pública para benchmark

A interface visual usa o mesmo endpoint que os agentes. Isso evita divergência entre o que um humano vê e o que uma automação mede.

GET {{ public_site_url }}/api/benchmark/v1/route?start_lat=-23.62326&start_lon=-46.69844&end_lat=-23.56147&end_lon=-46.65594&profile=driving&mode=smart&include_geometry=0
  • profile: driving, motorcycle, walking ou cycling.
  • include_geometry=0 é o padrão para agentes; use 1 apenas quando precisar inspecionar/desenhar a geometria.
  • O endpoint é somente leitura, não consome créditos de convidado e não grava histórico.

Como usar com IA

Aponte o agente primeiro para /api/benchmark/v1/capabilities. O JSON descreve os endpoints, parâmetros, limites, metodologia e o formato resumido de resposta.

  • Use a mesma origem/destino para reduzir ruído entre modos.
  • Execute múltiplas rodadas e reporte mediana/p95 de latência, não apenas uma chamada.
  • Compare ETA, trânsito, segurança e score VANO separadamente; um único número não representa toda a qualidade da rota.
